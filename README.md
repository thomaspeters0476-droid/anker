# Anker

Web-App für fokussiertes Tagesarbeiten — ADHS-freundlich: wenig planen, eine Sache, zurückfinden.

## Lokal starten

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Hosting

- **GitHub** — Quellcode
- **Vercel** — Deployment (Vite → `dist`)
- **Supabase** — aktuell nicht nötig (Daten liegen lokal im Browser). Später sinnvoll für Login, Sync zwischen Geräten oder Buddy-Cloud.

## Features (MVP)

- 2–3 Arbeit + Alltagsanker, Größen S/M/L, Kapazitätsdeckel
- Fokus-Timer + App-Buddy-Check-ins
- Geistesblitze (Notiz / Skizze / Audio), Speicher nach Arbeitsaufgaben
- Export: Kopieren, Text, PDF, Audio
