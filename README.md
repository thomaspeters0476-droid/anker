# Tagesanker

**Eine Sache. Realistisch. Zurückfinden.**

Web-App für fokussiertes Tagesarbeiten — ADHS-freundlich: wenig planen, eine Sache, sanft zurückfinden. Entlasten, nicht bewerten.

## Haltung

- **Kapazitätsbremse** statt „alles rein“
- **Eine aktive Aufgabe** — der Rest wartet absichtlich
- **Alltag zählt** gleichwertig — Stabilität vor „Produktivität“
- **App-Buddy** warm / kurz / klar, nicht bewertend
- **Daten lokal** im Browser (Testphase ohne Account)
